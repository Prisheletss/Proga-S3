# О репозитории

Данный репозиторий содержит в себе две папки: `Project` и `Демонстрационные модели`

## Project

Это основная папка для разработки основного приложения, содержит только основные программы, необходимые для работы продукта

Содержимое:
+ `обработка текстов` &mdash; папка, содержащая все скрипты для скачивания, обработки, парсинга, хеширования и токенизации классической русской литературы





<br>

## Демонстрационные модели

Это папка, содержащая в себе все модели, котороые учавствуют косвенным методом в разработке основного приложения. В основном, тут находятся программы, котороые необходимо показывать преподователю для отчётов о проделанной работе

Содержимое:
+ `распознователь части речи` &mdash; набор скриптов, предназначенный для работы однослойной нейронной сети, предназначенной для определения того, к какой части речи относится поданное ей слово
    + `training data` &mdash; папка, содержащая в себе все слова, на которых учится нейросеть
    + `итерации` &mdash; папка, содержащая в себе несколько временных срезов нейросети, на разных этапах обучения
    + `new network generator.py` &mdash; скрипт для генирации случайной однослойной нейросети 20x9
    + `database_initializer.py` &mdash; скрипт для превращения данных из папки `training data` в базу данных `data.db`
    + `database_trainer` &mdash; основная программа, содержащая все необходимые функии для обучения нейросети на данных
+ `рчр (многослойный)` &mdash; набор скриптов, предназначенный для работы многослойной нейронной сети, предназначенной для определения того, к какой части речи относится поданное ей слово (**НЕДОДЕЛАННО**)
