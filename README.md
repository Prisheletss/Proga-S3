# Водяные знаки для чат-ботов
Демонстрационная модель методов внедрения водяных знаков для языковых моделей

## Цель проекта
Разработать программно-апаратный комплекс со следующими приложениями:

Малая языковая модель (чатбот) &mdash; способна отвечать на промпты, как всем известные CatGPT и другие ей подобные, но при этом способная работать в двух режимах:
+ Unwatermarked-текст &mdash; подчиняется законам человеческой логики, ответы практически неотличимы от тех, которые бы писал живой человек
+ Watermarked-текст &mdash; невооружённым взглядом всё ещё выглядит, как написанный живым человеком, **но** законы статистики статистики в нём нарушены тем или иным образом из представленных, что позволяет программным методом отличить его от написанного человеком

<br>

Программа для проверки текста на watermarked-ность
